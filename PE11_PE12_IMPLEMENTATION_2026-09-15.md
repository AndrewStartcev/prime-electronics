# PE-11 / PE-12 — реализация 15.09.2026

## PE-11 — выбор характеристик SEO-подборки

Реализовано в админке SEO-подборок:

- ручные текстовые поля характеристики и значения заменены на выбор из реального каталога;
- доступные значения загружаются через существующий `GET /products/filters`;
- запрос учитывает выбранную категорию и выбранные бренды подборки;
- после выбора характеристики второй список содержит только доступные значения этой характеристики;
- формат хранения не менялся: `SeoCollection.attributes` остаётся объектом `name -> string[]`;
- сохранённые ранее характеристики/значения, которые больше не возвращаются текущим каталогом, не теряются при редактировании: они остаются доступными как сохранённые ранее значения.

Основной файл UI:

- `e-commerce-admin/src/widgets/SeoManagement/SeoManagement.tsx`

Backend API фильтров переиспользован без изменения контракта хранения SEO-подборок.

## PE-12 — одна плитка тегов в нескольких категориях

Добавлена поддержка нескольких категорий размещения одной SEO-плитки.

### Хранение

Добавлена таблица связей `SeoTagTileCategory` с составным ключом `(tagTileId, categoryId)`.

Миграция:

- `ecommerce-backend/prisma/migrations/20260915193000_seo_tag_tile_categories/migration.sql`

Миграция переносит все существующие одиночные связи из `SeoTagTile.categoryId` в новую таблицу, поэтому старые плитки не теряются.

Поле `SeoTagTile.categoryId` временно сохраняется как legacy-поле и содержит первую выбранную категорию для обратной совместимости со старым кодом и выгрузками.

### Backend

Добавлен отдельный сервис:

- `ecommerce-backend/src/seo/seo-tag-tile.service.ts`

Он:

- валидирует все выбранные категории;
- создаёт/обновляет связи плитки со всеми категориями;
- фильтрует публичные плитки по любой из связанных категорий;
- возвращает `categoryIds` и `categories`;
- не возвращает дубль одной плитки при запросе категории.

Существующие URL API сохранены:

- `GET /seo/tag-tiles?categoryId=...`
- `GET /seo/admin/tag-tiles`
- `POST /seo/admin/tag-tiles`
- `PATCH /seo/admin/tag-tiles/:id`
- `DELETE /seo/admin/tag-tiles/:id`

DTO поддерживает новый `categoryIds: string[]` и старый `categoryId`.

### Admin

В форме плитки вместо одиночной категории отображается список категорий с множественным выбором. В карточке существующей плитки показываются все категории размещения.

Обновлены:

- `e-commerce-admin/src/shared/api/seoApi.ts`
- `e-commerce-admin/src/widgets/SeoManagement/SeoManagement.tsx`
